# 儲存契約：照片相簿整理器

**功能分支**：`001-photo-album-organizer`

根目錄為後端 `storage/`，執行期產生，不納入版本庫。

## 原始檔儲存區

保存使用者上傳的照片副本；不修改、不刪除使用者裝置上的原始檔。

### 目錄結構

```text
storage/
├── tmp/
│   └── <upload_id>.part
└── originals/
    └── <hash_prefix>/
        └── <content_hash>.<extension>
```

### 命名規則

| 部位     | 規則                                                  | 例子                                            |
| -------- | ----------------------------------------------------- | ----------------------------------------------- |
| 暫存檔   | `tmp/` 底下以上傳識別命名，副檔名固定 `.part`         | `tmp/7c2a9e4b-2d11-4c0a-9f3e-1b8d6a0c4e21.part` |
| 雜湊前綴 | `content_hash` 前兩個十六進位字元                     | `a3`                                            |
| 正式檔   | `{content_hash}` 加原始副檔名（`jpg`／`png`／`heic`） | `originals/a3/a3f1…c90.jpg`                     |

### 新增與刪除連動

| 時機     | 規則                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 新增     | 串流寫入 `tmp/<upload_id>.part`；收完後原子改名到 `originals/<hash_prefix>/<content_hash>.<extension>`。正式路徑出現後才寫入資料列。 |
| 新增失敗 | 刪除對應 `.part`；不得留下正式路徑的半寫入檔。                                                                                       |
| 啟動清理 | 清除 `tmp/` 內殘留 `.part`，以及 `originals/` 中沒有對應資料列的檔案。                                                               |
| 刪除照片 | 資料列刪除成功後，再刪除該 `content_hash` 的正式檔。不觸碰使用者裝置上的原始檔。                                                     |
| 重複內容 | 寫入資料列因內容雜湊衝突失敗時，刪除本次暫存或剛改名的檔，保留既有正式檔。                                                           |

## 縮圖儲存區

保存前端上傳的 JPEG 縮圖；沒有縮圖的照片不建立檔案。

### 目錄結構

```text
storage/
└── thumbnails/
    └── <hash_prefix>/
        └── <content_hash>.jpg
```

### 命名規則

| 部位     | 規則                                   | 例子                         |
| -------- | -------------------------------------- | ---------------------------- |
| 雜湊前綴 | 與原始檔相同，取 `content_hash` 前兩碼 | `a3`                         |
| 正式檔   | `{content_hash}.jpg`                   | `thumbnails/a3/a3f1…c90.jpg` |

### 新增與刪除連動

| 時機     | 規則                                                            |
| -------- | --------------------------------------------------------------- |
| 新增     | 僅在請求附上縮圖時寫入；寫入成功後資料列 `has_thumbnail` 為 1。 |
| 無縮圖   | 不建立檔案，資料列 `has_thumbnail` 為 0。                       |
| 刪除照片 | 與原始檔同一時機刪除對應縮圖；檔案不存在時視為已清除。          |
| 重複內容 | 不覆蓋既有縮圖。                                                |
